# UNIDAD-1-EJERCICIO-15
Resolución del ejercicio N°15 de la unidad 1 de programación 2.
El código define una clase que gestiona las operaciones de carga y consumo de agua en un tanque con un límite fijado.
Esta lo va actualizando el nivel actual según las entradas y salidas de líquido, y mostrando los cambios de estado por consola.
